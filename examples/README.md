# Examples

Usage examples for the pdf-autofillr CLI.

| File | Description |
|---|---|
| `basic_usage.py` | Run common CLI commands from Python |
| `rag_workflow.py` | Full RAG workflow: init → predict → feedback → metrics |
| `mapper_workflow.py` | Mapper workflow: embed → fill |
| `doc_upload_workflow.py` | Doc upload: extract from document and fill PDF |
